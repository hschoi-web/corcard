# Ledger — 법인카드 사용 내역

법인카드 지출을 기록하고 월별로 살펴보는 브라우저용 MVP입니다.

## 실행

`index.html`을 브라우저에서 열면 바로 사용할 수 있습니다. 별도의 패키지 설치나 빌드 과정은 필요하지 않습니다.

## 기능

- 사용 내역 등록, 수정, 삭제
- 가맹점·메모·카드 소유자 검색과 항목·월별 필터
- 월 지출 합계, 사용 건수, 평균 지출, 최다 지출 항목 요약
- 현재 필터에 해당하는 내역을 CSV로 다운로드
- 카드 번호는 끝 4자리만 입력

첫 실행에는 화면 예시를 위한 샘플 내역이 표시됩니다. 데이터는 현재 브라우저의 `localStorage`에 저장되므로 같은 브라우저에서 다시 열어도 유지되지만, 사용자 간 공유·로그인·서버 백업은 제공하지 않습니다.
